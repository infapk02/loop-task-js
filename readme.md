# JavaScript Loop Practice

A collection of beginner-friendly JavaScript exercises focused on loops, conditional statements, number operations, and logical problem-solving. This project is part of my journey to strengthen my JavaScript fundamentals and build a solid foundation for MERN stack development.

## 📚 Topics Covered

- `for` loop and `while` loop
- `break` and `continue` statements
- `if` conditions and logical operators
- Odd and even number identification
- Perfect square number detection
- Sum calculation using loops
- Multiplication table generation
- Countdown sequences
- Counters and accumulators

## 📝 Practice Tasks

| No. | Task Name                   | Description                                                          |

| 03  | Perfect Square Detection    | Find the first perfect square greater than 1 between 1 and 100.      |

## 💡 Key JavaScript Concepts

**1. `break`** — Stops a loop immediately when a specified condition is met.

**2. `continue`** — Skips the current iteration and moves to the next iteration.

**3. Modulus operator (`%`)** — Helps identify odd and even numbers.

**4. Accumulator variable** — Stores and updates a running total inside a loop.

**5. Increment (`++`) and decrement (`--`)** — Increase or decrease a variable by one.

**6. `Math.sqrt()` and `Number.isInteger()`** — Help determine whether a number is a perfect square.
